## 🧑‍💻 About Me

I'm an **Associate Software Engineer** with about a year of production experience at **Firewires OneIoT**, where I build React and TypeScript interfaces for a multi-client IoT SaaS platform.

- 🔧 Led a **TypeScript migration** across a large React codebase
- 🎨 Built **white-labelled and role-based dashboards**, infinite scroll, pagination and **Zod-validated forms**
- ⚡ Refactored **time-series data tables** for performance
- 🤝 Work daily with designers and back-end engineers to ship responsive, SEO-friendly UI and integrate REST APIs
- 🤖 Exploring **LLMs, RAG and Hugging Face**, and building AI-powered full-stack apps in Python
- 🌱 Currently looking for **Frontend, Full Stack and AI-focused engineering roles**
